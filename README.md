Bank Management System

Project Description:

This is a Python-based Bank Management System developed using Object-Oriented Programming (OOP).
It helps users manage bank accounts and perform basic banking operations easily.

Features:

Create Account,
Deposit Money,
Withdraw Money,
Transfer Money,
Check Balance,
Search Account,
Display All Accounts,,
View Transaction History.

Technologies Used:

Python,
OOP Concepts,
UUID module.

Project Goal:
To develop a simple banking application that manages customer accounts and transactions efficiently.
